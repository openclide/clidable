Clidable: CLI Coding Agents for everyone

Clidable makes CLI Coding Agents easy to use and accessbile for everyone. Users can take advantage of all the benefits of using CLI Coding Agents but with a beautiful and intuitive UI.

Clidable provides:
- Textbox input instead of terminal input
- Checkpoints before every message
- Preview of projects (iframe/webview opens the webserver)
- Easy Plugin/Skill/MCP management, for example, using "npx skills", "npx add-mcp", "npx plugins add" behind the scenes
- Easy AI team management for orchestration between the differen CLI coding agents
- Multi-agent/multi-terminal management
- Create projects right inside the tool
- Codemirror/VS Code for Code edition
- Glassmorphism and modern UI
- Mobile-friendly
- Runs as a desktop app and as a web app on the browser
- Runs locally or in a server
